# LinkedIn Project Announcement

I’m excited to share my latest machine learning project: **Cyber Threat Detection using ML**! 🚀🛡️

As cyber threats become increasingly sophisticated, traditional security measures are often pushed to their limits. For my latest portfolio project, I wanted to explore how data science can be leveraged to secure networks autonomously.

Using the benchmark NSL-KDD dataset, I engineered an end-to-end Python pipeline to classify network traffic as either benign or anomalous. 

**Key Technical Highlights:**
🔹 Data preprocessing: One-hot encoding, zero-variance filtering, and standard scaling.
🔹 Trained & evaluated multiple models: Logistic Regression, Decision Trees, and Random Forest.
🔹 Achieved state-of-the-art accuracy with the Random Forest ensemble.
🔹 Extracted feature importances to identify the most critical network traffic indicators of a cyber attack.

This project was a fantastic deep dive into both cybersecurity concepts and robust machine learning engineering practices.
